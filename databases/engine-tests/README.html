Tests de moteurs positions tactiquesEngine tests tactical positions

Un recueil de positions à résoudre : le moteur cherche chaque position pendant un temps fixé, Hydra64 compte celles où il trouve le coup de la solution.

A collection of positions to solve: the engine searches each position for a fixed time, and Hydra64 counts those where it finds the solution move.

UtilisationHow to use

Moteur → Test de solutions… : choisissez un moteur, un recueil de ce dossier et le temps par position, puis Lancer. Chaque ligne montre le coup proposé par le moteur pendant sa recherche, puis le résultat ; « Trouvé en » est le moment depuis lequel le moteur garde la bonne solution en tête (s'il en change ensuite, le temps repart).

Engine → Solution test…: choose an engine, a collection from this folder and the time per position, then Start. Each row shows the move the engine proposes while searching, then the result; “Found in” is the moment from which the engine keeps the right solution on top (if it changes its mind later, the time restarts).

Le score final donne le nombre de positions résolues et le temps moyen de solution. Double-clic sur une ligne : la position s'ouvre dans la page Analyse. La fenêtre peut être fermée pendant le test, qui continue.

The final score gives the number of positions solved and the average solving time. Double-click a row to open the position in the Analysis page. The window can be closed while the test keeps running.

Le Tactics Marathon : 210 positions de combinaison tirées de l'Encyclopedia of Chess Middlegames (le numéro de chaque position, « 946 ECM », est dans le champ Tournoi). La solution est le premier coup de la partie ; une variante au premier coup est une autre solution acceptée, ou un piège à éviter si elle est marquée « ? ». Certaines positions donnent la suite complète de la combinaison.

The Tactics Marathon: 210 combination positions from the Encyclopedia of Chess Middlegames (each position's number, “946 ECM”, is in the Event field). The solution is the first move of the game; a variation on the first move is another accepted solution, or a trap to avoid when marked “?”. Some positions give the full combination.

Repère : Stockfish récent, 1 seconde par position, en résout 169 sur 210. Une partie des solutions vient d'analyses humaines anciennes qu'un moteur moderne conteste : un score de 100 % n'est pas attendu, c'est l'évolution du score entre deux moteurs ou deux réglages qui compte.

Benchmark: a recent Stockfish at 1 second per position solves 169 of 210. Some solutions come from old human analysis that a modern engine disputes: a 100% score is not expected, what matters is how the score changes between two engines or two settings.

Hydra64 reads the bm (best move, several allowed), am (avoid move) and id (position name) operations.
  • PGN ou base Hydra64 : une partie par position (en-tête FEN), le premier coup est la solution, comme pour le Tactics Marathon.PGN or Hydra64 database: one game per position (FEN header), the first move being the solution, as in the Tactics Marathon.
